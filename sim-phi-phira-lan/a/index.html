连接 B 端服务器

这台设备（A 端）无法直接访问互联网。请在同一局域网内的 Windows 电脑上运行 PhiraHub 服务器，然后填写它的地址。

怎么找到 B 端的 IP？
  1. 在 B 端（Windows）运行 setup.bat，窗口里会打印本机局域网 IP。
  2. 也可以在 B 端命令行执行 ipconfig，找「无线局域网适配器 WLAN → IPv4 地址」，通常形如 192.168.x.x。
  3. 确保平板和电脑连接同一个 Wi-Fi，且 B 端端口已在防火墙放行（setup.bat 会处理）。
  4. 连接成功后会自动记住地址，下次打开自动重连。

关于局域网模式

A 端所有 Phira 请求（列表 / 详情 / 封面 / 曲谱包）都会转发到 B 端，由 B 端访问互联网。 因此 B 端必须保持运行；断开后仍可从「我的曲库」载入已下载的曲谱离线游玩。
