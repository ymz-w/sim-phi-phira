# sim-phi-phira

基于 [sim-phi](https://github.com/lchzh3473/sim-phi)（Simulation of Phigros display with JavaScript Canvas API）的非官方 Fork。

本 Fork 在保留原始模拟器小窗与核心逻辑的前提下，重做了现代化 UI，并新增 Phira 曲谱浏览、详情查看、下载到 IndexedDB、曲谱管理与加载游玩能力。支持通过 `file://` 直接打开使用；已下载曲谱可在离线状态下从 IndexedDB 加载并正常游玩。

此项目只是为了实现目的, 项目结构方面可能没有顾及.

使用dsh编写.

另外本人不怎么懂fork, 所以暂时没有使用fork.

> 非官方项目，与 Phigros / Phira 官方无关。曲谱资源版权归原作者所有，本项目仅提供客户端浏览、下载与本地缓存功能。
